# UD01_Actividad04_Conversores

Aplicación de consola en **Kotlin** para convertir divisas, distancias y temperaturas mediante un menú interactivo.

## Autor

- **Nombre:** NombreApellidos
- **Módulo:** PMDM – UD01. Introducción

## Requisitos

- IntelliJ IDEA
- JDK 17 o superior

## Funciones

- Conversión de euros a dólares, libras, yenes y francos suizos.
- Conversión de distintas unidades de distancia.
- Conversión entre Celsius, Fahrenheit y Kelvin.
- Validación de datos introducidos por teclado.

## Archivos

- `Main.kt`: contiene el menú principal.
- `Depurar.kt`: contiene los conversores y las funciones de validación.

## Cómo ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Abrir `Main.kt`.
3. Ejecutar la función `main()` con el botón verde.

## Estructuras utilizadas

- `when` e `if`
- Bucles `do-while` y `while`
- `try-catch`
- Variables `val` y `var`
